# AI Usage Disclosure — Project 3 IFN-I

## 1. AI Tool and Model

**AI tool:** ChatGPT  
**Model:** GPT-5.6 Luna

## 2. Project Context

Generative AI was used specifically as an assistant for **Project 3: Type I Interferon Immunotherapy Response — Single-Cell RNA-Seq Analysis**.

AI assistance was limited to activities directly related to this Project 3 analysis.

## 3. Purposes of AI Use

AI assistance was used for:

- learning the single-cell RNA-seq workflow required for Project 3;
- understanding the Project 3 Student Project Guide and practical workflow;
- explaining Scanpy and Python analysis steps;
- troubleshooting and debugging Project 3 analysis scripts;
- interpreting error messages and correcting code;
- checking analysis outputs and numerical consistency;
- organizing Project 3 analysis results and figures;
- documenting the executed computational pipeline;
- interpreting IRC analysis in relation to the Project 3 guide and primary paper;
- drafting and proofreading the Project 3 final report.

## 4. Project 3 Analysis Areas Supported by AI

AI assistance was used in connection with the following Project 3 workflow:

1. 10x Genomics data loading and validation
2. Sample combination
3. Quality-control filtering
4. Normalization and highly variable gene selection
5. PCA
6. Nearest-neighbor analysis
7. UMAP
8. Leiden clustering
9. Marker-gene analysis
10. Cell-type annotation
11. Six-gene IFN-I response-capacity (IRC) scoring
12. T-cell IRC validation
13. IRC-high versus IRC-low differential expression
14. Hallmark GSEA
15. T-cell subtype-aware validation
16. Figure organization and final report preparation
